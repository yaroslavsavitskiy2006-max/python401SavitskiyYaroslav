# Решения задач по Python

Тридцать учебных задач по основам Python в одном файле `solutions.md`. Примеры охватывают преобразование типов, условия, циклы, работу с последовательностями, сортировку, строки и простые алгоритмы.

## Темы

- Типы данных, преобразования и логические выражения.
- Условия, циклы и числовые вычисления.
- Реализации операций, похожих на `map`, `filter`, `zip`, `enumerate` и `reversed`.
- Сортировка, поиск, строки и последовательность Фибоначчи.

Решения приведены как фрагменты кода в Markdown. Отдельный исполняемый модуль и набор автоматических тестов в репозитории не предусмотрены.
